                  使用步驟

                  • 解壓縮到隨身碟或電腦；建議把舊電腦的 D:\專題 整包複製到 專題\。
                  • 雙擊 專題安裝.exe，按確定後保持網路連線，看黑色視窗的 1/9–9/9 進度，不要關閉。
                  • 中途失敗時修好問題（通常是網路）再執行一次，已完成的步驟會自動跳過。
                  • 完成後雙擊桌面「啟動機器」，等於在 Miniforge Prompt 執行 conda activate lerobot → set PYTHONPATH=src → cd software → python examples/4_xlerobot_teleop_keyboard.py；啟動器也可選擇 Xbox、Joy-Con 等範例。
                  • 舵機板驅動（CH340／CH343）：Win11 通常自動安裝；裝置管理員看不到 COM 埠時，再到 Waveshare／WCH 官網下載。
